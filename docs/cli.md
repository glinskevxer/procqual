# arc command reference

Generated by `npm run reference`. Do not edit by hand.

## assign

who may weld what

### arc assign check

whether a welder may take a joint

```
arc assign check [options] <joint> <welder>
```

- `--process <code>` (required) — the process to be used
- `--consumable <code>` (required) — the consumable to be used
- `--on <date>` — the day the work would be done

### arc assign who

everyone who could take a joint today

```
arc assign who [options] <joint>
```

- `--process <code>` (required) — the process to be used
- `--on <date>` — the day the work would be done

## joints

the weld map

### arc joints map

put a joint on the weld map

```
arc joints map [options] <id>
```

- `--vessel <tag>` (required) — the vessel it belongs to
- `--description <text>` (required) — where it is on the vessel
- `--category <letter>` (required) — A, B, C or D
- `--type <number>` (required) — construction type, 1 to 7
- `--weld <kind>` — groove or fillet [default: groove]
- `--form <kind>` — plate or pipe [default: plate]
- `--position <name>` (required) — flat, horizontal, vertical or overhead
- `--thickness <length>` (required) — as 1/2 or 0.5
- `--length <length>` (required) — length of weld, in inches
- `--diameter <length>` — outside diameter, for a pipe joint
- `--left <specification>` (required) — base metal on one side
- `--right <specification>` (required) — base metal on the other
- `--heat-left <number>` (required) — heat number on one side
- `--heat-right <number>` (required) — heat number on the other
- `--procedure <number>` (required) — the procedure it is welded to
- `--radiography <level>` — full, spot or none [default: full]

### arc joints list

```

- `--vessel <tag>` — narrow to one vessel

### arc joints show

```

- `--lethal` — the vessel is in lethal service

### arc joints level

change how much radiography a joint gets

```
arc joints level [options] <id> <level>
```

- `--reason <text>` (required) — who agreed it and why

## nde

examinations and repairs

### arc nde technician

put an examination technician on the register

```
arc nde technician [options] <name>
```

- `--level <roman>` (required) — I, II or III
- `--methods <list>` (required) — comma separated, as RT,UT
- `--until <date>` (required) — the day the certification runs out

### arc nde technicians

who may interpret what, and who is about to run out

```
arc nde technicians [options]
```

- `--on <date>` — read it as it stood on this day

### arc nde file

file an examination report

```
arc nde file [options] <id>
```

- `--joint <id>` (required) — the joint examined
- `--method <code>` (required) — RT, UT, MT, PT or VT
- `--technician <name>` (required) — who read it
- `--on <date>` (required) — the day it was taken
- `--report <number>` (required) — the laboratory report number
- `--coverage <length>` (required) — length of weld covered
- `--extent <kind>` — full, spot or partial [default: full]
- `--after-pwht` — taken after the heat treatment
- `--indication <spec...>` — type:size:position, repeatable

### arc nde list

the examinations on file

```
arc nde list [options]
```

- `--joint <id>` — narrow to one joint

### arc nde required

what the code asks for on a joint

```
arc nde required [options] <joint>
```

- `--lethal` — the vessel is in lethal service

### arc nde coverage

spot radiography, increment by increment

```
arc nde coverage [options] <joint>
```

### arc nde repair

raise a repair against a rejected examination

```
arc nde repair [options] <id>
```

- `--joint <id>` (required) — the joint
- `--from <report>` (required) — the examination that rejected it
- `--defect <type>` (required) — what was found
- `--length <length>` (required) — length of the excavation
- `--depth <length>` (required) — depth of the excavation
- `--on <date>` (required) — the day it was gouged out
- `--welder <stencil>` (required) — who is rewelding it
- `--attempt <number>` — which go this is at the same place [default: 1]
- `--approval <reference>` — engineering approval, where one is needed

### arc nde rates

the repair rate for every welder and process

```
arc nde rates [options]
```

- `--on <date>` — read it as it stood on this day
- `--suspended` — only the ones over the suspend level

### arc nde repairs

the repairs raised, open ones first

```
arc nde repairs [options]
```

- `--joint <id>` — narrow to one joint

## weld

### arc weld log

record a run of weld

```
arc weld log [options] <id>
```

- `--joint <id>` (required) — the joint on the map
- `--welder <stencil>` (required) — who welded it
- `--process <code>` (required) — the process used
- `--procedure <number>` (required) — the procedure followed
- `--on <date>` (required) — the day it was welded
- `--role <kind>` — root, fill, cap, repair or tack [default: fill]
- `--consumable <code>` (required) — the stock code of the consumable
- `--lot <number>` (required) — the lot or heat number of the tin or reel
- `--deposit <length>` (required) — weld metal laid in this run
- `--foreman <name>` (required) — who signed for it

### arc weld void

```
arc welders used [options] <stencil> <process>
```

- `--on <date>` (required) — the day

### arc welders coupon

record a performance qualification coupon

```
arc welders coupon [options] <number>
```

- `--welder <stencil>` (required) — who ran it
- `--process <code>` (required) — the process used
- `--position <code>` (required) — the test position, as 3G
- `--filler <number>` (required) — the F number of the filler used
- `--deposit <length>` (required) — weld metal deposited
- `--layers <count>` (required) — layers deposited
- `--on <date>` (required) — the day it was welded
- `--witness <name>` (required) — who witnessed it
- `--base-metal <pNumber>` (required) — P number of the coupon material
- `--fillet` — a fillet coupon rather than a groove one
- `--pipe <diameter>` — a pipe coupon of this outside diameter
- `--backing` — welded onto backing
- `--downhill` — welded downhill
- `--failed` — the coupon did not pass its tests

### arc welders production

qualify a welder on a production radiograph instead of a coupon

```
arc welders production [options] <welder> <joint> <report>
```

- `--process <code>` (required) — the process used
- `--on <date>` (required) — the day the weld was run
- `--transfer <mode>` — the transfer mode, where it matters

### arc welders continuity

who is current, who has lapsed and who is about to

```
arc welders continuity [options]
```

- `--on <date>` — read it as it stood on this day
- `--due <days>` — show only those lapsing inside this many days
